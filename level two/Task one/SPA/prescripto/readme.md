# 🚀 Single Page Application (SPA)

reate a simple Single Page Application using React or
Vue.js. The application should have at least three
pages (e.g., Home, About, and Contact) with smooth
navigation without full page reloads

---



## 🛠️ Technologies Used

- HTML5 (Semantic Elements)
- CSS3 (Flexbox / Grid)
- JavaScript (Basic Interactivity)
- React JS
- Sweet Alert


---


### ✅ Task 1: SPA

- Use React Router or Vue Router for navigation.
- Maintain state across pages using state management 
- Ensure fast navigation and smooth transitions. 
- Deploy the SPA on a platform like Netlify or Vercel.
---

## 📱 Responsiveness

The landing page is fully responsive and works smoothly on:

- 📱 Mobile Devices  
- 💻 Tablets  
- 🖥️ Desktop Screens  

---

## 🎯 Project Goal

To practice building a professional landing page while improving skills in responsive design, layout structuring, and basic JavaScript interactions.
