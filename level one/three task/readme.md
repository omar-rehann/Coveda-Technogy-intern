# 🚀 Basic DOM Manipulation

Build a counter application that demonstrates basic
DOM manipulation using vanilla JavaScript. The
counter should have increment, decrement, and reset
buttons with a display showing the current count

---



## 🛠️ Technologies Used

- HTML5 (Semantic Elements)
- CSS3 (Flexbox / Grid)
- JavaScript (Basic Interactivity)

---

## 📋 Tasks Completed

### ✅ Task 3: Basic Dom manpulation

- Use JavaScript to dynamically update the DOM.
- Implement event listeners for button clicks.  
- Ensure the counter doesn’t go below zero.  
- Style the app for a minimalistic design. 
---
